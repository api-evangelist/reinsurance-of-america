# Reinsurance Group of America

Reinsurance Group of America (RGA) is a leading global provider of life and health reinsurance and financial solutions, serving clients in more than 70 countries. RGA offers digital health data scoring APIs, underwriting automation, risk assessment tools, and client portal integrations for insurance carriers and reinsurers.

**URL:** [apis.yml](https://raw.githubusercontent.com/api-evangelist/reinsurance-of-america/refs/heads/main/apis.yml)

## APIs

| Name | Description |
|---|---|
| [Digital Health Data Scoring API](https://www.rgare.com/solutions/all-products-and-services) | Real-time API for evaluating structured electronic medical record and claims data to derive underwriting risk scores. |
| [RGA Central Portal API](https://www.rgare.com) | Client portal providing single point of access to exclusive applications, underwriting tools, and analytics. |
